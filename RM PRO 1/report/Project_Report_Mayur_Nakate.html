Abstract

Metropolitan bus transit systems are critical for sustainable urban mobility; however, growing vehicular density and mixed-traffic conditions trigger severe congestion bottlenecks that impair schedule reliability and increase passenger transit delays. Traditional Geographic Information Systems (GIS) rely predominantly on static choropleth maps and aggregated post-hoc statistics that obscure the localized propagation of traffic shockwaves over space and time.

This project, “Visualizing Spatiotemporal Traffic Congestion Patterns Using Dynamic Folium and Mapbox Layers: A Case Study of Metropolitan Bus Transit Networks,” presents a comprehensive data-driven visual analytics framework to evaluate and monitor urban transit congestion. Using high-resolution spatiotemporal bus GPS trajectory records collected across key arterial corridors in Pune metropolis, this project formulates the Speed Performance Index (SPI), Transit Congestion Index (TCI), and Travel Rate Delay Deficit to quantify velocity degradation. An unsupervised density-based clustering algorithm (DBSCAN with Haversine spherical distance metric) is implemented to autonomously detect recurrent structural bottlenecks and differentiate them from transient incidents.

A high-performance interactive web dashboard developed with Python, Streamlit, Folium, and Mapbox GL (PyDeck) provides synchronized temporal heatmap playback sliders (HeatMapWithTime), animated directional vehicle trajectory vectors (AntPath), 3D extruded hexagon density columns, and interactive corridor delay analytics. The system enables transit planners to isolate critical chokepoints with over 75% speed degradation, supporting dynamic Transit Signal Priority (TSP) and schedule adjustment.

1. Introduction

1.1 Objective

The objective of this project is to develop an interactive, data-driven spatiotemporal visualization and analytical system that monitors traffic congestion dynamics and identifies structural bottlenecks in metropolitan bus transit networks. The system processes Automated Vehicle Location (AVL) GPS trajectories, computes normalized congestion indices, executes unsupervised spatial density clustering, and renders dynamic time-slider heatmaps and trajectory vectors.

1.2 Novel Idea

Unlike basic GIS transit viewers that display static polyline routes or tabular delay records, this project integrates Leaflet client-side temporal animation (HeatMapWithTime) with hardware-accelerated 3D WebGL cartography (Mapbox GL / PyDeck). It incorporates Haversine DBSCAN clustering to autonomously identify persistent structural chokepoints and quantify their spatial influence radius and Bottleneck Severity Score (BSS).

1.3 Significance

Urban transit fleets suffer from severe schedule instability and bus bunching due to arterial chokepoints. This project provides empirical evidence for municipal traffic authorities to deploy dynamic Transit Signal Priority (TSP), adjust dispatch headways, and export standard GeoJSON spatial layers directly into QGIS and ArcGIS Pro.

1.4 Specifications

Software & Libraries: Python 3.14, Streamlit 1.65, Folium 0.20, Branca, PyDeck 0.9.3, Pandas, NumPy, Scikit-Learn, SciPy, Plotly Express.
Hardware: Multi-core CPU, 8GB+ RAM, WebGL2 capable GPU.
Dataset: 34,441 GPS trajectory records across 4 arterial corridors and 18 transit stops in Pune metropolis over a 15-hour operating window (07:00 to 22:00).

2. Literature Survey

The research builds on seminal works in movement analytics and intelligent transportation systems: Zheng (2015) established core trajectory mining principles; Wang et al. (2021) in IEEE T-ITS evaluated spatiotemporal traffic congestion waves; Tang et al. (2016) in ISPRS Int. J. Geo-Inf. demonstrated the necessity of network-constrained mining; Mazloumi et al. (2010) analyzed GPS travel time unreliability; Giesen and Wang (2019) evaluated Folium and Leaflet for transit monitoring; and Zhang et al. (2023) demonstrated WebGL Mapbox pipelines for dense 3D vehicle trajectory rendering.

3. Methodology

The system follows a 9-step scientific methodology:

Workflow Pipeline:
1. Transit Network Modeling → 2. Trajectory Ingestion → 3. Index Computation (SPI, TCI, Delay) → 4. Exploratory Data Analysis → 5. Haversine DBSCAN Spatial Clustering → 6. Bottleneck Severity Scoring (BSS) → 7. Folium TimeSlider Heatmap & AntPath → 8. Mapbox 3D Hexagon Deck → 9. Web Dashboard & GeoJSON Export.

4. Implementation

The application is modularized across src/data_generator.py, src/congestion_analyzer.py, src/folium_layers.py, src/mapbox_layers.py, and src/export_utils.py. The interactive dashboard is implemented in app.py using Streamlit and Plotly.

7. Conclusion

This project successfully implemented an integrated spatiotemporal traffic congestion visualization and bottleneck mining platform using Python, Folium, and Mapbox GL. Standardized indices (SPI, TCI) and Haversine DBSCAN clustering accurately identified critical urban bottlenecks with over 75% speed degradation, providing actionable operational tools for transit agencies.

8. Future Scope

Future enhancements include streaming GTFS-Realtime (GTFS-RT) feeds, Spatiotemporal Graph Convolutional Networks (ST-GCN) for 30-minute queue forecasting, and automated APIs for Adaptive Traffic Control Systems (ATCS).
